## Shop thú cưng Flutter

## *Thông tin project Source code website thương mại điện tử cửa hàng thú cưng Flutter API PHP Mysql

## *Các Chức năng

### 1.User
- **Trang người dùng**
- **Đăng ký tài khoản, đăng nhập người dùng**
- **Tìm kiếm phân trang sản phẩm**
- **Xem thêm sản phẩm**
- **Chi tiết sản phẩm**
- **Giỏ hàng**
- **Xem các đơn hàng đã mua**
- **xem trạng thái sản phẩm, thông tin sản phẩm, khách hàng**

### 2. Admin
- **Trang quản trị phân quyền dùng**
- **Đăng nhập admin**
- **Tổng quan (Dashboard)**
- **Quản lý đơn hàng**
- **Quản lý sản phẩm**
- **Quản lý danh mục**
- **Thêm sửa xóa sản phẩm, danh mục, CRUD, Search**
- **Phân quyền người dùng**
- **Thống kê doanh thu tổng quan**
